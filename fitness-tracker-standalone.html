How scoring works

  • Logged day — any field filled (metrics, supplements, notes, etc.).
  • Consistency — logged days ÷ days in the window (7 or 30).
  • Habit checks (on logged days only):
    • Supplements Morning / Noon / Night — pass if Yes or N/A; fail if No or blank.
    • Training — pass if Yes, No, or Rest; fail if blank.
    • Adherence — pass if 1–10 set; fail if blank.
    • Water / Steps goals — only if a goal is set in Settings; pass when met, otherwise fail. Skipped if no goal.
  • Habit hit rate — passed checks ÷ applicable checks across logged days. Shows “—” if none apply.
  • Blend — round(40% × consistency + 60% × habit hit). If habit hit is unavailable, blend = consistency only.
  • Streak — consecutive logged days ending today, or yesterday if today is still empty.
